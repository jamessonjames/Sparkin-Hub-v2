# Sparkin Hub - Extensão de Captura para WhatsApp Web (Zero-Config)

Esta extensão conecta o **WhatsApp Web** ao seu painel **Sparkin Hub**, enviando resumos de conversas e áudios pré-analisados por IA direto para a sua **Caixa de Entrada (`/inbox`)**.

---

## 📌 Como Instalar no Google Chrome (Passo a Passo)

1. Abra o navegador **Google Chrome**.
2. Digite na barra de endereços: `chrome://extensions` (ou acesse **Menu > Mais ferramentas > Extensões**).
3. No canto superior direito, **ative a chave "Modo do desenvolvedor"**.
4. Clique no botão **"Carregar sem compactação"** (Load Unpacked).
5. Selecione a pasta `extension` do projeto `Sparkin Hub`.
6. Prontinho! A extensão aparecerá com o ícone do Sparkin Hub no seu navegador.

---

## ⚡ Como Funciona

- **Zero-Configuração**: Você não precisa configurar nada dentro da extensão. Todas as preferências (frequência de leitura, limite de mensagens por cliente e modelo de IA) são gerenciadas diretamente no Sparkin Hub em **Configurações > WhatsApp Business**.
- **Segurança**: A extensão lê apenas os contatos/grupos dos clientes cadastrados no seu sistema e roda exclusivamente dentro do seu navegador.
